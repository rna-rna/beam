Below is an updated version of your GalleryLightbox component that addresses the two main issues:

Clicking the comment icon should keep the crosshair cursor active until you toggle it off, allowing you to drop a comment pin on each click.
Comments can be dragged freely in real time (i.e., they visibly move as you drag).
Important:

Since the actual comment-drag behavior is mostly handled inside the CommentBubble component, the changes below assume you can pass an onDrag callback (for continuous drag updates) and an onDragEnd callback (for the final position) to CommentBubble.
If your CommentBubble does not currently support these callbacks, you will need to implement them (using something like framer-motion or react-draggable) so that the bubble’s position updates live during the drag.
The example below demonstrates how to wire up the real-time position changes from the child bubble to the parent’s state so that you see the bubble move immediately.
Key Changes
Keep isCommentPlacementMode active after placing a pin.

Removed the line setIsCommentPlacementMode(false) so the user can keep placing multiple pins (if desired).
If you want them to exit pin mode after placing just one comment, then you can still remove the line—but then you lose the “multiple pins” functionality.
Real-time dragging in CommentBubble:

Added onDrag and onDragEnd props.
onDrag updates the comment’s position in the React Query cache (or local state) continuously so the comment bubble moves as you drag.
onDragEnd can be used to finalize the position on the server, if necessary.
Ensure the crosshair cursor is visible by applying it to the same element (.gallery-container) that has your click handler, and ensuring it has no conflicting pointer-events: none.

What Changed?
Continuous Crosshair / Comment Mode

The isCommentPlacementMode remains true after placing one comment pin (we removed the setIsCommentPlacementMode(false)). This way the cursor stays a crosshair, and you can place multiple pins if you want.
If you only want the user to drop one pin at a time, you can reintroduce setIsCommentPlacementMode(false) inside handleImageClick.
Real-Time Dragging

In the snippet, the key is passing both onDrag and onDragEnd (or your chosen callback names) down to CommentBubble.
onDrag(newX, newY) updates the comment’s position in the React Query cache immediately, so you see the comment bubble move as you drag.
onDragEnd is optional if you want to do a final server update once the user releases the mouse.
Pointer Events

The top-level overlay for comments uses pointer-events: none, but each comment bubble has pointer-events: auto. This ensures the user can still click or drag the comments themselves, while clicks on empty space go through to the underlying container to place new pins.
The “crosshair” cursor is applied to the .relative.flex... wrapper in the motion.div that also handles the container’s click event.
With these updates:

Clicking the comment icon correctly changes the cursor to a crosshair (until toggled off).
Dropping a comment pin is possible on any click in the image area.
Dragging comments is real-time and unrestricted (within whatever logic you put in CommentBubble).
You’ll just need to confirm that your CommentBubble component honors the onDrag/onDragEnd callbacks appropriately for smooth real-time movement.
